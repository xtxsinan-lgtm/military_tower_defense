01 · 任务
保卫什么（★ 白色地标）
死守地图中央偏南的 3 座民生设施：★ 热电厂（全城供电核心）、★ 中心变电站、★ 水厂。
02 · 兵力
手里的防空武器
• 皮卡高射机枪组 ×4：双联机枪 + 探照灯，子弹无限，前推专打廉价无人机。
• IRIS‑T ×1 / NASAMS ×1：专打巡航导弹，全关仅十余发，别浪费在无人机上。
03 · 敌情
主攻方向与盲区
东路：无人机群直扑热电厂。
西北河谷：巡航导弹贴着北山脊后的红色雷达盲区低飞，偷袭变电站与水厂。（小圆点是自动工作的听音 / 目视暗哨，战中不用管）
指挥要点 · KEY TASKS
  1. 布防堵路把皮卡机枪摆在东面无人机来路上当“筛子”，把防空导弹护在电厂和变电站周围，用雷达 + 暗哨照亮山脊盲区。
  2. 开火纪律点击地图上的导弹车或打开指挥台 F3 火控，一键设为“只打导弹”，防止好导弹被无人机骗光。
  3. 电磁博弈雷达和 NASAMS 开机越久越容易暴露（引来反辐射导弹）。看右栏参谋建议随时切闪烁 / 关机 / 转移阵地。
