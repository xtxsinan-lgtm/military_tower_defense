### 2.1 SimRandom 测试向量（00）

按 00 §3.1 的文字描述独立实现 PCG32（`pcg32_srandom_r` / `pcg32_random_r`）+ SplitMix64 + FNV‑1a 64 子流派生 + `Bounded` 拒绝采样 + `NightSeed`，并按 §3.7.1 实现 `StateHasher` 编码（`verify_simrandom.py`）。结果：T-00-01..10、T-00-24 共 **56 项比对全部一致（FAILS: 0）**，包括 18 个子流种子、嵌套派生 `e42`、`NextDouble` 逐位值、`NextInt` 拒绝分支、T-00-07 的消耗次数断言。T-00-12/13/14/34 的换算、取整、方位角、高程解码也逐位一致（`verify_00_misc.py`）。00 的 RNG 部分可以直接交给编码代理实现。
