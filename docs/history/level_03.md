# 第 3 关 · 米科拉伊夫（2022.07）

> 对应 GDD 12.1 / 12.2 第 3 关；战役关卡设计 v1 第 3 关。资料截至 2026-10-15。
> 本文件只整理公开来源；部队番号只写到"某旅"一级，人物不写姓名（GDD 第 17 章）。造船厂等设施在游戏中应虚构名称与位置（GDD 17.4）。

## 1. 历史背景（3–6 句话概述）

米科拉伊夫是南布格河与因古尔河交汇处的港口和造船城市，位于通往敖德萨的主要道路上 [1][7]。2022 年 3 月俄军进攻受阻、被推回赫尔松州后，城市成为距前线很近的"前线城市"，从春季到 11 月赫尔松反攻结束几乎每天遭到炮击和导弹打击 [1][2]。据市长 2022 年 6 月下旬的说法，落到城里的弹药约八成是"龙卷风""飓风"一类火箭炮发射的子母弹 [4]；7 月 8 日州长称俄军开始用 S‑300 防空导弹打击地面目标 [3][8]。7 月间两所主要大学被导弹击中，月底城市遭到据市长称"迄今最猛烈"的轰击 [2][5]。4 月起，从第聂伯河引水的主输水管道被毁，城市只能改用南布格河的咸水作为"技术用水"，饮用水要排队领取 [1][6]。

### 3.2 乌方防空 / 防御手段

- 米科拉伊夫当时的具体防空部署（型号、数量、阵地）**未公开**（≈）。GDD 配置的 Buk‑M1、S‑300PS、高炮、单兵导弹均属开战时乌军装备（时间表 2.1），作为游戏化配置合理。
- 公开资料强调：火箭炮子母弹和 S‑300 对地这类目标**防空几乎无法拦截** [3][4]；乌方在 S‑300 对地问题上的声明本身也注意到其中可能混有乌军防空导弹失效坠落的情况 [8]。
- 民防：城市以"技术用水"管道 + 饮用水分发点维持供水 [4][6]。

## 4. 地理

- **城区形态**：主城区位于南布格河一个约 180° 大弯内的半岛上，因古尔河在城东北汇入；城北有几条狭长的半岛 [7]。地形平坦（南乌克兰草原）[7]。
- **河流与桥梁**：南布格河上有一座开合桥（瓦尔瓦里夫卡桥），3 月战斗中是通往敖德萨的关键通道 [1][7]；因古尔河上也有桥梁连接东部城区 [7]。
- **城区分布**：中央区在西北（含历史中心、瓦尔瓦里夫卡等）；因古尔区在东部（含火车站、汽车站、动物园）[7]。
- **港口**：城市是重要的河海港口 [7]。
- **来袭方向**：前线在城市南面和东南面（赫尔松州方向）[1]，距离很近，这是预警时间短的直接原因（≈：为推论）。
- **机场**：城东南有一座军用机场，西北有民用机场 [7]（可作为背景地标，不建议做成玩家保护目标）。
- **地图建议**：以河弯半岛为主城区，水体包围三面；供水设施（游戏中虚构）放在城外取水口附近；港口区沿南布格河；前线方向放在东南，预警最短。

## 5. 可用于关卡设计的要点

1. **"预警时间"机制**有依据：前线近、S‑300 对地和火箭炮几乎不可拦截 [3][4]。建议 S‑300 对地以"几乎无预警、只能分散部署减损"表现。
2. **"有些东西拦不住"**：市长称多数落弹是火箭炮子母弹 [4]，与战役关卡设计"第一次让玩家感受到有些东西拦不住"的目的吻合。
3. **水厂作为保护目标**有强史实支撑：主输水管道被毁，城市依赖南布格河咸水和分发点供水 [1][4][6]。建议做成"技术用水泵站 + 饮用水分发点"两个目标。注意：管道是在俄占区被破坏的（不是被空袭打掉），关卡里的水厂遭空袭属于游戏化处理。
4. **港口 / 造船厂**：俄方曾声称打击城内造船厂 [1]；游戏中造船厂须使用虚构名称（GDD 17.4）。
5. **"约 4 周 3 夜"的时间结构**可对应 7 月的节奏：7.02 缟玛瑙 → 7.08 S‑300 对地公开 → 7.15 大学被击中 → 7.26 大规模导弹打击 → 7.31 最猛烈轰击 [3][5][10][11]。
6. **库存制苏制导弹**：与时间表 2.1"S‑300 弹药持续消耗"一致，具体到米科拉伊夫的库存数字无公开来源。
