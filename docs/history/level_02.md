# 第 2 关 · 沃兹涅先斯克（2022.03.02–03）

> 对应 GDD 12.1 / 12.2 第 2 关；战役关卡设计 v1 第 2 关。资料截至 2026-10-15。
> 本文件只整理公开来源；部队番号只写到"某旅"一级，人物不写姓名（GDD 第 17 章）。

## 1. 历史背景（3–6 句话概述）

沃兹涅先斯克是米科拉伊夫州的一座小城（人口约 3.5 万），位于南布格河畔，有跨南布格河的桥梁，距南乌克兰核电站不远 [1][2]。2022 年 3 月初，俄军在包围赫尔松、进攻米科拉伊夫的同时，分出一支纵队北上，试图在这里找到渡过南布格河的通道 [1]。守城的是本地国土防卫营（平民志愿者）、正规军部队和炮兵，市长和本地企业主组织设置路障、炸毁城内默尔特沃德河上的一座桥，并挖开河岸让装甲车无法涉渡 [1][2]。俄军先炮击城市，伞兵在城西南机降，装甲纵队从东南方向推进，但未能攻入城区；乌军炮兵、反坦克导弹和步兵反击，并击落一架 Mi‑24 [1][2]。3 月 3 日俄军撤退，丢下大量车辆和装备 [1][2]。乌克兰媒体认为此战阻止了俄军包围米科拉伊夫并向敖德萨推进 [1]。

## 4. 地理

- **河流**：城市位于南布格河畔，默尔特沃德河穿城而过并汇入南布格河 [1][2]。南布格河上的桥梁是俄军的目标 [1]；被炸毁的是城内默尔特沃德河上的一座桥 [1][2]。城内还有一座铁路桥（守军曾经由此撤出）[4]。
- **来袭方向**：地面纵队从东南（米科拉伊夫 / 叶兰涅茨方向）沿 P55 公路接近，在城东南的拉科韦集结；伞兵降落在城西南和安德里伊奇科韦一带 [1][5]。
- **城区**：博尔加尔卡小区在城市边缘，是俄军进出城区的位置；城郊入口处有一座加油站被俄军用作据点 [4]。
- **周边**：南乌克兰核电站在附近（GDD 提到的地名关系正确）[1][2]；地图上**不应**做成可被攻击的目标。
- **地图建议**：一张以河流切分的小镇地图——南布格河作为主屏障，默尔特沃德河上有可炸毁的桥；东南方向公路 + 村庄（集结区），西南田野（机降区），城内铁路桥作为撤退路线。

## 5. 可用于关卡设计的要点

1. **炸桥（一次性技能）**有直接史实依据：守军炸毁城内一座桥并挖开河岸，迫使纵队走预设路线 [1][2]。建议在关卡中把"炸哪座桥"做成开局选择。
2. **工程机械堵路、把纵队引进炮火区** [2]：可作为炸桥之外的被动加成（地图上的"路障点"）。
3. **民众报告坐标** [2]：与第 3 关"民众上报"系统呼应，可在本关做一个不需操作的提示版本。
4. **机降点在城外开阔地** [1]：GDD"击退机降"的胜利条件有依据；建议机降波次出现在西南田野。
5. **Orlan 标记机制**属于游戏化设计（本战未找到 Orlan 使用记载），但与 2022 年俄军普遍的侦察—炮击模式一致（时间表 1.5）；保留无妨，文案中不要写成"史实"。
6. **"坚守 3 个阶段"**可对应史实节奏：检查站迟滞（3.01–02 上午）→ 城郊攻防与机降（3.02 白天）→ 夜间反击与敌撤退（3.02 夜–3.03）[1][5]。

## 6. 敏感内容提示

- 战斗期间有平民遇难，俄军撤退时炮击了拉科韦村的诊所 [1]。**不做成关卡内容，只在历史对照中提及**；不要在关卡里出现被击中的医疗设施。
- 双方伤亡与俘虏数字多为乌方单方面说法 [1][2]，不在游戏中引用。
- 市长、指挥员、阵亡人员在公开报道中有姓名 [1][4][5]，游戏中一律虚构。
- 俄方阵亡人员遗体处理等细节见于报道 [5]，**不使用**。
