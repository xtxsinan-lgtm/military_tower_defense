# 《守夜》Nightwatch（暂定名）

以俄乌战争（2022.02 – 2026.05）为背景的**硬核军事塔防 / 策略游戏**。玩家扮演乌克兰的防空指挥官，在信息不完整、资源永远不够的情况下提前部署防空网，迎接一夜又一夜的空袭，决定保护什么、放弃什么。

- **平台**：Steam（Windows + macOS）
- **引擎**：Godot 4（.NET 版）+ C#
- **美术**：写实 2.5D（夜战实景层 + 防空指挥台风格的指挥层）
- **开发方式**：个人开发 + AI 辅助
